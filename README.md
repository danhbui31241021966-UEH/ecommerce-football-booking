12. README.md – NỘI DUNG TÓM TẮT DỰ ÁN
12.1. Giới thiệu
Website đặt sân bóng đá mini 5/7 người tại TP.HCM giúp khách tìm sân, xem giá và lịch trống, đặt một sân con theo slot cố định và theo dõi trạng thái ngay trên web. Hệ thống đồng thời hỗ trợ Chủ sân quản lý sân, slot, giá, booking, thanh toán và lịch đặt ngoài website nhằm hạn chế overbooking.
12.2. Khách hàng mục tiêu
• B2C: người chơi bóng đá phong trào, trưởng nhóm/đội trưởng chịu trách nhiệm tìm và đặt sân.
• B2B: chủ sân và đơn vị quản lý cụm sân bóng đá mini tại TP.HCM.
12.3. Chức năng chính
• Tìm/lọc sân, xem giá và lịch trống mà không cần đăng nhập.
• Đăng ký/đăng nhập khách hàng; tạo booking 1 sân con/1 slot.
• Auto-confirm hoặc chờ duyệt 05 phút theo cấu hình sân; quản lý trạng thái booking.
• Chủ sân CRUD sân/sân con, cấu hình slot/giá, chặn lịch ngoài web và quản lý booking.
• Ghi nhận thanh toán/hoàn tiền ở mức trạng thái; không tích hợp payment gateway trong MVP.
• Admin cấp tài khoản Chủ sân và hỗ trợ ngoại lệ có giới hạn.
12.4. Công nghệ dự kiến
Lớp	Công nghệ
Frontend	HTML5, CSS3, JavaScript
Backend	Node.js + Express
Database	MySQL
Version Control	Git + GitHub (Issues/Pull Request)
Triển khai	Chốt ở giai đoạn triển khai; ưu tiên nền tảng phù hợp Node.js và database MySQL.
